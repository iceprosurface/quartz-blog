# icepro`s blog

这里是 icepro 博客的源码站，由于 obisidian 本身的博客内容中存在一些敏感内容（部分可能存在密码等），所以单独划分了一块区域用于对外发布。

他们会使用 github action 的方式合并到这个仓库，通常标题是 ：

```
sync from the knowledge base
```

本身知识库和对外展示会逐渐适配 quartz ，所以在很长一段的时间内浏览体验肯定是不如之前的。


# 使用说明

如果你希望使用本项目为模板新建一个文档站点，我建议使用 [quartz](https://quartz.jzhao.xyz/) 作为基础模板，并参考 [我的文章](https://iceprosurface.com/blog/moc/) 酌情修改，而不是直接 fork 或是 copy 本仓库，由于我部分代码使用了非规范的方式添加（包括单不限于 日志收集、评论点击量上报等），他们在你的站点可能会产生意料之外的行为。
